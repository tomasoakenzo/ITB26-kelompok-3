# Company Profile Kelompok — Panduan Singkat

Halo! Ini template website Company Profile buat kelompok kalian di IT Bootcamp HIMTIKA Unsika.

## Struktur Folder

```
company-profile/
├── index.html          <- Isi/struktur halaman (edit teks di sini)
├── css/
│   └── style.css       <- Tampilan & warna
├── js/
│   └── script.js       <- Interaksi kecil (menu mobile)
└── assets/
    ├── poster/         <- Taruh file poster STBI di sini
    └── foto-tim/       <- Taruh 1 foto bersama Kabing + semua anggota di sini
    └── logo/           <- Taruh logo Himtika dan IT Bootcamp 2026 disini
```

## Cara Deploy ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload semua isi folder ini (index.html, css/, js/, assets/) ke repo tersebut.
3. Masuk ke **Settings > Pages**, pilih branch `main` dan folder `/ (root)`.
4. Tunggu 1-2 menit, link website akan muncul di halaman Settings > Pages.
